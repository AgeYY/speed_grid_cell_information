Please download grid cell spiking data from https://figshare.com/articles/dataset/Toroidal_topology_of_population_activity_in_grid_cells/16764508?file=35078602. And put the whole folder under your DATAROOT (default is ./data/), i.e. the structure should be like this:

```
DATAROOT/
    - Toroidal_topology_grid_cell_data/
        - rat_q_grid_modules_1_2.npz
        - ...
```
